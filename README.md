# Blog Application

## Overview

This is a simple full-stack Blog Application built to gain hands-on experience with frontend and backend development. The application allows users to view blog posts, browse posts by category, and manage profile information.

## Features

* View latest blog posts
* Browse blogs category-wise
* User profile management
* CRUD operations for blog posts
* REST API integration


## Tech Stack

### Frontend

* React
* React Router
* CSS / Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Purpose

The primary goal of this project was to:

* Practice building REST APIs
* Understand CRUD operations
* Learn frontend and backend integration
* Work with MongoDB database operations
* Gain experience in full-stack application development

## API Functionality

* Create blog posts
* Read blog posts
* Update blog posts
* Delete blog posts
* Fetch posts by category
* Manage user profile data
